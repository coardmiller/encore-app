# Encore website

Public marketing, support, privacy and terms pages for Encore: Concert Tracker (iOS).
Static Next.js export deployed to GitHub Pages: https://coardmiller.github.io/encore-app/

Adapted from the FishLogger website. Legal and support text mirrors `docs/launch/` in the Encore app repo.
Screenshots are native simulator captures using the app's sample concerts.
To launch: set `APP_STORE_LIVE = true` in `src/lib/site.mjs`.
